Registry API

Read package metadata and search the published registry over HTTP.

Search packages

GET /v5.2/package/search?q=<term>

Returns matching package records with the latest version, available versions, publisher, download count, and scope.

Read package dependencies

GET /api/v1/package/<name>/dependencies?scope=<scope>

Returns the package's dependencies and dev_dependencies lists. The scope parameter disambiguates packages with the same name.
